# NYC-Traffic-Accidents-In-Excel
Each row in the dataset represents an auto accident happened in NYC. The columns have attributes about the incident, such as time, location, and contributing factor.

Using pivot table, I calculated the number of accidents by month and year and visualized them using line chart.
